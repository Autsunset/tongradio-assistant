# 星瞳直播助手 · TongRadio Assistant

> 看 B 站直播睡着了，直播结束 / 进入轮播时，自动切到你的电台随机播放（或关掉标签页）；主播开播时发系统通知。
> 兼容 **Chrome / Edge / Firefox**。

---

## ✨ 功能

- **直播结束 / 进入轮播** → 自动把直播间标签页切到你的电台随机播放，或直接关掉标签页
- **开播提醒** → 监控一个或多个主播，从「未开播 / 轮播」变「直播中」时发系统通知
- **两种监控范围** → 固定监控某个主播（输入 UID），或监控所有打开的 B 站直播间标签页
- **电台地址可自定义** → 换域名 / 用本地端口，面板里直接改
- **设置自动保存** → 存在浏览器同步存储，换电脑登录账号可同步

## 📦 安装

### 从 GitHub Releases 下载

在页面右侧 **Releases** 里选最新版本，按你的浏览器下载对应 zip（解压后就是能直接选的文件夹）：

| 浏览器 | 下载 |
|:--|:--|
| Chrome / Edge | `tongradio-assistant-chrome-src.zip` |
| Firefox | `tongradio-assistant-firefox-src.zip` |

### Chrome 安装步骤

1. 下载并解压 zip，得到 `chrome-src` 文件夹（里面能看到 `manifest.json` 就对）
2. 在浏览器**地址栏输入** `chrome://extensions/` 回车，进入扩展页
3. 打开页面**右上角**的 **「开发者模式」** 开关
4. 点左上角 **「加载已解压的扩展程序」** → 选中 `chrome-src` 文件夹
5. 工具栏出现 📻 图标即安装成功，点击即可设置

### Edge 安装步骤

1. 同上，下载解压得到 `chrome-src` 文件夹
2. 地址栏输入 `edge://extensions/` 回车
3. 打开**左侧**的 **「开发人员模式」** 开关
4. 点 **「加载解压缩的扩展」** → 选中 `chrome-src` 文件夹
5. 📻 图标出现即安装成功

### Firefox 安装步骤

1. 下载解压得到 `firefox-src` 文件夹
2. 地址栏输入 `about:debugging#/runtime/this-firefox` 回车
3. 点 **「临时载入附加组件」** → 选中 `firefox-src` 文件夹里的 `manifest.json`
4. 📻 图标出现即安装成功
5. ⚠️ 临时加载的扩展**重启 Firefox 后会消失**，需重新加载（日常自己用够用）

> 更新版本：Chrome/Edge 在 `chrome://extensions/` 里点该插件的 **🔄 刷新** 即可。

## ⚙️ 设置

点工具栏 📻 图标打开面板，所有设置**自动保存**：

| 设置 | 说明 |
|:--|:--|
| ① 监控范围 | 固定直播间（输入主播 UID，默认星瞳）或所有打开的直播间标签页 |
| ② 播完动作 | 切到电台随机播放（电台地址可改）或关闭标签页 |
| ③ 轮询间隔 | 每 30 秒 / 1 分钟 / 2 分钟 / 5 分钟 |
| ④ 开播提醒 | 开关 + 监控的 UID 列表，实时显示 直播中 / 轮播中 / 未开播 |
| ⑤ 可靠模式 | 自动播放保底，**默认开启**（见下） |

底部两个按钮：
- **立即检查**：手动触发一次轮询，看最近检查时间
- **测试播完动作**：对当前直播间标签页立刻执行一次切电台 / 关闭，用来验证

## 🔧 可靠模式（自动播放是怎么回事）

浏览器为了防骚扰，**默认禁止网页自动播放声音**（Chrome 尤其严格，连静音播放也会拦）。这会导致「切到电台后不自动响」。

扩展用三层方案解决：

1. **可靠模式（默认开启）**：用浏览器的调试接口向电台页注入一次「带用户手势的播放」——相当于模拟你点了一下播放键，几乎 100% 生效。切换瞬间浏览器顶部会闪过一条「正在调试此浏览器」的提示条，切完自动消失，属正常现象。
2. **普通注入**：可靠模式不可用时（比如你开着 DevTools 调试网页）自动回退。
3. **页面兜底**：极端情况仍被拦时，电台页会显示「▶ 点击开始随机播放」按钮，点一次之后浏览器就记住该网站了。

## 🔒 权限说明

| 权限 | 用途 |
|:--|:--|
| `storage` | 保存设置 / 运行时状态 |
| `alarms` | 后台定时轮询直播状态 |
| `notifications` | 开播系统通知 |
| `tabs` | 找到直播间标签页并切换 / 关闭 |
| `scripting` | 向电台页注入播放 |
| `debugger` | 可靠模式：注入「带手势的播放」 |
| `api.live.bilibili.com` | 查询直播状态 |
| `radio.autsun.asia` | 默认电台域名（自动播放注入需要） |

插件**不收集任何用户数据**，请求只发往 B 站官方 API 和你自己配置的电台地址。

## ❓ FAQ

**Q：切到电台后没自动播放？**
A：先确认「⑤ 可靠模式」是开着的（默认开）。如果开着还不行，多半是你开着 DevTools 调试导致回退到了普通方案 —— 关掉 DevTools 再试。个别环境仍被拦时，电台页有「点击开始随机播放」兜底按钮，点一次即可。

**Q：换电台域名 / 用本地端口？**
A：面板「② 播完动作 → 电台地址」改成新地址即可，无需重新打包。

**Q：触发有延迟？**
A：轮询间隔最长 5 分钟；睡觉场景用默认的 1 分钟即可。

**Q：Firefox 临时加载重启就没了？**
A：是的，临时加载只对当次会话有效；要永久使用需自行签名（搜索「Firefox 扩展签名」）。
